# Calculadora Científica em Java

[🚀 Experimentar versão web](https://igorsilvadev01.github.io/-calculadora-java-swing/)

Calculadora científica com interface gráfica desenvolvida em Java Swing. O projeto possui um layout compacto, inspirado na calculadora do Windows, com suporte a operações matemáticas, memória e histórico de contas.

## Recursos

- Soma, subtração, multiplicação e divisão.
- Porcentagem, potência e resto da divisão.
- Raiz quadrada e raiz cúbica.
- Quadrado e cubo de um número.
- Inverso (`1/x`) e valor absoluto.
- Seno, cosseno e tangente.
- Logaritmo comum (`log`) e logaritmo natural (`ln`).
- Fatorial.
- Constantes `π` e `e`.
- Arredondamento de valores.
- Memória com `MC`, `MR`, `M+`, `M-` e `MS`.
- Histórico de contas realizadas.
- Suporte a números decimais com ponto ou vírgula.
- Suporte a operações pelo teclado.

## Tecnologias

- Java 17 ou superior.
- Java Swing.

## Como executar

Abra o terminal na pasta do projeto e compile o arquivo:

```bash
javac Main.java
```

Depois, execute a aplicação:

```bash
java Main
```

## Como usar

Digite os números pela interface e selecione a operação desejada. O botão `=` calcula o resultado e registra a conta no histórico.

O histórico pode ser acessado pelo botão **Histórico** e apagado pelo botão **Apagar histórico**.
